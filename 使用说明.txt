更新 GitHub Pages 的步骤：
1. 打开仓库：https://github.com/zye674746-coder/ninghai18
2. 点开 index.html，点右上角铅笔 Edit；如果文件太大无法编辑，就回到仓库主页，选择 Add file → Upload files。
3. 将本包里的 index.html 上传并覆盖旧的 index.html。不要删除现有仓库里的其他文件。
4. 如果使用 Upload files，请把本包里的 index.html 拖进去；若提示同名文件，按页面提示提交替换。
5. 在 Commit changes 区域提交更改。
6. 等 1–3 分钟，打开 https://zye674746-coder.github.io/ninghai18/ ，Mac 浏览器按 Command + Shift + R 强制刷新。
7. 检查首屏是否显示迎会手绘图、故事播放按钮是否能播放。
